▶ Lihat Perhitungan
Permisalan:
x = harga 1 Hiasan Dinding Pixel Art
y = harga 1 Serangga hasil Elektronik

Permodelan:
Paket 1 : 2x + y = 115.000
Paket 2 : 2x + 2y = 160.000

Penyelesaian:
• Eliminasi
2x + y = 115.000
2x + 2y = 160.000
____________________ -
-y = -45.000
-y = -45.000 ÷ (-1)
y = 45.000

•Substitusi
2x + y = 115.000
2x + 45.000 = 115.000
2x = 115.000 - 45.000
2x = 70.000
x = 70.000 ÷ 2
x = 35.000

Kesimpulan:
x = Rp. 35.000,00
y = Rp. 45.000,00

Jadi harga 1 Hiasan Dinding Pixel Art adalah Rp. 35.000,00 dan harga 1 Serangga Kupu-kupu Elektronik adalah Rp. 45.000,00

▶ Lihat Perhitungan
Permisalan:
x = harga 1 Jam Dinding Click Clock
y = harga 1 Kupu-kupu

Permodelan:
Paket 1 : 2x + 3y = 195.000
Paket 2 : x + y = 80.000

Penyelesaian:
• Eliminasi
2x + 3y = 195.000 (x1)
x + y = 80.000 (x3)
__________________
2x + 3y = 195.000
3x + 3y = 240.000
__________________ -
-x = -45.000
x = 45.000

•Substitusi
x + y = 80.000
45.000 + y= 80.000
y = 80.000 - 45.000
y = 35.000
Kesimpulan:
x = Rp. 45.000,00
y = Rp. 35.000,00

Jadi harga 1 Jam Dinding Click Clock adalah Rp. 45.000,00 dan harga 1 Kupu-kupu adalah Rp. 35.000,00
